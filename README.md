
# CalculadoraJava

Calculadora de consola desarrollada en Java como proyecto personal para practicar programación y reforzar los conocimientos adquiridos en el Grado Superior de Desarrollo de Aplicaciones Multiplataforma (DAM).

## Funcionalidades

- Suma, resta, multiplicación y división.
- Menú interactivo que permite realizar varias operaciones.
- Validación de entradas numéricas.
- Control de opciones no válidas.
- Prevención de divisiones entre cero.

## Tecnologías utilizadas

- Java
- IntelliJ IDEA
- Scanner para la entrada de datos por consola.

## Cómo ejecutar el proyecto

1. Clona o descarga este repositorio.
2. Abre el proyecto en IntelliJ IDEA.
3. Comprueba que tienes un JDK instalado.
4. Ejecuta el método `main` de la clase `Main`.

## Objetivo

Proyecto de aprendizaje orientado a practicar estructuras de control, entrada de datos, operaciones aritméticas y validación de errores en Java.
